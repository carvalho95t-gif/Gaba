Banco de dados

Conexão guardada neste aparelho:

A anon key é pública por natureza e vai dentro do app: quem protege o banco é o login, porque as políticas só atendem quem está dentro. A service_role nunca entra aqui.

O endereço e a chave vêm no próprio pacote (js/credencial.js), então nenhum aparelho precisa digitar nada. Digite aqui apenas se este celular deva apontar para outro banco.

Cópia de segurança

Baixe um arquivo .json com todas as suas escolas, turmas, alunos, provas, versões e correções. Se precisar restaurar, o próprio Gaba lê o arquivo de volta.

O arquivo fica no seu computador ou celular. Nada é enviado para nenhum servidor externo.
